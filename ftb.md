# DegeneracyCraft Official Quests

This directory contains the official **FTB Quests** data for **DegeneracyCraft**.

Installing FTB Quests allows you to explore DegeneracyCraft while viewing explanations of its academic fields, machines, and gameplay systems.

The quest data is **not required** to play the mod, but it is recommended for tracking your progression and following the intended technological development.

It also serves as an in-game guide and documentation.

---

# Installation

1. Install **FTB Quests**.
2. Download the latest quest package from the **Releases** page.
3. Extract the downloaded archive.
4. Copy the **`ftbquests`** folder into your Minecraft instance configuration directory:

```text
.minecraft/
└── config/
    └── ftbquests/
        └── quests/
```

The extracted `ftbquests` folder should be placed directly inside the `config` directory.
If the `ftbquests` directory already exists, it is recommended to create a backup before replacing the files.
---

# Compatibility

* Minecraft **1.20.1**
* Forge **47.x**
* DegeneracyCraft **Compatible Version**
* FTB Quests **Compatible Version**

# Notes

* The quest data is updated occasionally alongside DegeneracyCraft's development. The update frequency depends on the mod's development progress.
* Compatibility with older versions is not guaranteed.
* Backing up your world and configuration files before updating is strongly recommended.
* These quests are primarily maintained for mod development and progress tracking, so some sections may be incomplete, experimental, or not fully balanced.
