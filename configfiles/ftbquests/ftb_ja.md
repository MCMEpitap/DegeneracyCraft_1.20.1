# DegeneracyCraft 公式クエスト

このフォルダには **DegeneracyCraft** 用の **FTB Quests** クエストデータが含まれています。

FTB Quests を導入すると、学術分野や機械、システムの解説を確認しながら DegeneracyCraft を進めることができます。

クエストはMODプレイに必須ではありませんが、進行度合いを確認し、プレイを進行していく上では推奨です。

ゲーム内ガイドとして利用できます。

---

# 導入方法

1. **FTB Quests** を導入します。
2. このフォルダ内の **`quests`** フォルダを Minecraft インスタンス（またはサーバー）へコピーします。

```
.minecraft/
└── config/
    └── ftbquests/
        └── quests/
```

既に `ftbquests` 以降のフォルダが存在する場合は、必要に応じてバックアップを作成したうえで上書きしてください。

# 対応バージョン

* Minecraft **1.20.1**
* Forge **47.x**
* DegeneracyCraft **対応バージョン**
* FTB Quests **対応バージョン**

# 注意事項

* クエストデータは DegeneracyCraft のアップデートに合わせて（たまに）更新されます。これはMOD開発状況に比例します。
* 古いバージョンとの互換性は保証されません。
* 更新前にはワールドや設定ファイルのバックアップを推奨します。
* 主にMOD開発用であり、作者の進捗確認を兼ねているため適切ではない場合があることにご留意ください。
